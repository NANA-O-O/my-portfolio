# 李琳娜 · AI产品运营作品集

一个懂数据的文科生，正在 AI 产品运营的路上死磕自己。

- 单文件 HTML（CSS + JS 内联），无外部依赖，可直接部署到 GitHub Pages
- 打开方式：直接访问 `index.html`，点击开场头像进入作品集

## 目录结构
```
portfolio/
├── index.html        # 网站本体
├── .nojekyll         # GitHub Pages 静态发布标记
└── images/           # 图片资源（替换为你自己的照片）
```

## 部署到 GitHub Pages
1. 新建 GitHub 仓库（Public）
2. 把本文件夹里的所有文件推送到仓库
3. Settings → Pages → 选择分支发布
4. 绑定自己的域名（见 DNS 配置说明）
